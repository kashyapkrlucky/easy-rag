# Release notes

## Version 2.4

Version 2.4 adds partial restores with `--path` and raises the maximum snapshot size to
4 TB. It removes the deprecated `NIMBUS_COMPRESSION` setting; compression is now always
enabled with zstd.

## Version 2.3

Version 2.3 adds bandwidth limits through `NIMBUS_MAX_UPLOAD_MBPS` and arm64 support for
the agent.
